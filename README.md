# Task 7 - Sales Summary using SQLite and Python

## Objective
To connect Python with a SQLite database, extract sales data using SQL, and visualize it.

## Tools Used
- Python
- SQLite
- Pandas
- Matplotlib

## What I Did
- Created a SQLite database with sample sales data.
- Wrote a SQL query to summarize quantity sold and revenue.
- Used pandas to load SQL results.
- Plotted a bar chart showing revenue per product.

## Output
- Printed sales summary in the console.
- Saved bar chart as `sales_chart.png`.

## How to Run
1. Run `sales_summary.py`
2. It will display results and save the chart.
